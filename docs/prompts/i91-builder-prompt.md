## 🔴 两道陷阱题,别绕过去

issue 的决定 1 和 2 里各埋了一个,明说给你,因为绕过去比答错更浪费时间:

**一、限流状态放在哪里。** 如果它跟着连接走,**攻击者断开重连就重置了**,限流等于没有。你选的方案必须回答这个,而不是回避它。

**二、限流触发不等于恶意。** `peer.rs` 已有一套评分封禁体系,把限流直接接上去很自然——但一个诚实而实现拙劣的对端会持续踩线,那样你惩罚的是 bug,不是攻击。**这条边界画在哪,是你要表态的,不是我。**
