## 1. Wire bytes/note (framing overhead included)

`raw` = note-discovery amortized accounting (cm 32 + tag 8 + clue 1 + ⌈1088/k⌉).
`framed` = the full §2 compact group serialized by this reference (adds
tx_index varint + n_recipients + n_outputs per group).

| amortization | raw B/note | framed B/note | framing overhead | doc target |
|---|---|---|---|---|
| 1-of-1 | 1129 | 1132.0 | 3 B/group (3.0 B/note) | ~1.1 KB |
| 2-of-1 | 585 | 586.5 | 3 B/group (1.5 B/note) | ~600 B (585 measured) |

Framing overhead is a fixed **3 B per per-tx group** (tx_index 1 + n_recipients 1 + n_outputs 1)
for the single-recipient case — independent of the 1,088-B ct and the entry count.
The response wrapper adds version 1 + n_blocks(varint) + per-block height(varint) + n_groups(varint).

Whole devnet range (heights 1..=8): 55338 compact bytes over 72 notes = 768.6 B/note framed.

Wall time is **connection-bound**: the reference client uses `Connection: close`
(one TCP round-trip per fetch) and the decoy hook is ON (≥1 decoy per matched
fetch), so ~33 localhost connections dominate — not the ML-KEM decap (54k/s,
PR #28). It is an honest end-to-end localhost number for this reference, not a
tuned-transport ceiling (HTTP keep-alive / batched /full would raise it).
